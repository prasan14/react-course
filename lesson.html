Think in components

React helps you build user interfaces from small, reusable pieces. These pieces are called components—and learning to think in components is the first big step toward writing better React code.

✦
In this lesson

Understand what components are, why they matter, and how to describe a UI as a tree of reusable pieces.

01

What is a component?

A component is a self-contained piece of UI. It can be as small as a button or as large as a full page. In React, components are usually JavaScript functions that return markup written in JSX.

Welcome.jsx
function Welcome() {
  return <h1>Hello, React!</h1>;
}

That small function can be reused anywhere in your app. As your UI grows, you compose components together instead of repeating the same markup.

02

Compose your interface

Imagine a learning dashboard. Instead of writing one giant page, split it into meaningful parts. Each part has a clear job and can be developed or improved independently.

App
Topbar
CourseCard
Progress
A UI can be described as a tree of components.
03

Make components reusable

Reusable components accept inputs called props. A single CourseCard component can display different courses by receiving a title, duration, or level.

Remember this

Keep components focused, name them clearly, and extract repeated UI when it makes your code easier to understand.
